# Hi, I’m Arqila

I’m an Information and System Technology student at Institut Teknologi Bandung, based in Bandung, Indonesia.

I like building things that connect AI with real products. My work usually moves between model-backed features, computer vision, backend systems, and the interfaces people actually use. I’m especially interested in taking an idea from an early prototype to something reliable enough to use.

Most of my projects involve Python, TypeScript, Go, Next.js, FastAPI, databases, and practical machine-learning systems.
